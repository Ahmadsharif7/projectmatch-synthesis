# ProjectMatch Synthesis 🌌

> **AI-Driven Capability Mapping & Team Synthesis Platform**  
> Synthesized from Stitch Project `14182157273518573210` with high-precision glassmorphism, WebGL GLSL background shaders, and 3D Three.js capability topologies.

---

## ✨ Features

- **🪐 3D Interactive Capability Topology (Three.js)**: Real-time resonance core with 5 orbiting satellite capability nodes, raycasting, mouse orbit controls, and capability inspection.
- **🌌 Ambient WebGL Atmospheric Shader**: Real-time GLSL fragment shader rendering atmospheric pulses in Electric Violet, Cyan, and Magenta.
- **🛡️ Synthesis Command Center (`#overview`)**: Hero topology overview, high-signal project recommendations with count-up animated percentages, and bookmarking.
- **🔍 Projects Discovery Engine (`#discover`)**: Real-time search (`Ctrl+K`), stack filter chips, circular SVG match gauges, AI match rationales, capability vector telemetry, and market velocity metrics.
- **📂 Capacity Management (`#projects`)**: Team seat allocation visualizers (e.g. 4/5 filled) and interactive "Post New Project" creation flow.
- **📬 Connection Activity Center (`#requests`)**: Dynamic status tracking (Pending with live countdown timers, Accepted, Declined) with interactive Accept/Decline action handlers.
- **👤 Maya Chen Capability Profile (`#profile`)**: Capability signature sliders with live weight tuning and selected builds gallery.
- **⚡ Command Palette & Toast Notifications**: Global keyboard shortcuts (`Ctrl+K`), fast search, and interactive feedback.

---

## 🛠️ Tech Stack

- **Core**: Vanilla HTML5 & ES6+ JavaScript Modules
- **Styling**: Custom Glassmorphism Design System (CSS3, Space Grotesk & Inter typography, Material Symbols)
- **3D Graphics**: Three.js (v0.160+)
- **Shaders**: WebGL 1.0 GLSL Fragment Shaders
- **Tooling**: Vite

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm / yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Ahmadsharif7/projectmatch-synthesis.git
cd projectmatch-synthesis

# Install dependencies
npm install

# Start development server
npm run dev
```

### Building for Production
```bash
npm run build
npm run preview
```
